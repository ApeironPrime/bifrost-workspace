# Bifrost

Real-time, meeting-centric collaboration platform.

## Project structure

- `client/`: React + Vite + TypeScript frontend
- `server/`: Express + Socket.IO + TypeScript backend

## Run locally

1. Run the backend: `cd server` then `npm run dev`.
2. Run the frontend: `cd client` then `npm run dev`.

The backend health endpoint is available at `http://localhost:3000/api/health`.
